# Carbon Impact Level Prediction

This project is a **Machine Learning classification project** where I used Support Vector Machine (SVM) to predict the carbon impact level.

### What I Did

* Encoded the categorical columns using LabelEncoder
* Scaled the features using StandardScaler
* Split the dataset into training and testing sets
* Trained an SVM classification model
* Checked the training and testing accuracy

### Results

* Training Accuracy: **71.16%**
* Testing Accuracy: **67.50%**

The model achieved **67.5% accuracy** on the test data.

### Tools Used

Python, Pandas, NumPy, Scikit-learn, Jupyter Notebook

### Project Goal

The main goal of this project was to understand how SVM can be used for classification and how preprocessing like encoding and feature scaling affects the model.
